# Clauge Test App

A test application built to explore the file explorer and Git workflow features in Clauge.

## Features

- REST API structure with Express-style routes
- React components
- Utility helpers
- Unit tests

## Getting Started

```bash
npm install
npm start
```

## Running Tests

```bash
npm test
```

## Project Structure

```
.
├── components/     # React components and styles
├── src/
│   ├── components/ # UI components
│   ├── config/     # Configuration files
│   ├── middleware/ # Express middleware
│   ├── models/     # Data models
│   ├── routes/     # API routes
│   └── utils/      # Utility functions
├── tests/          # Unit tests
├── index.js        # Application entry point
└── package.json    # Project metadata
```
